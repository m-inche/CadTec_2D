# cadtec_2d
CADTec 2D es un motor CAD web que funciona en el navegador con HTML5 Canvas y Tailwind CSS. Permite dibujo técnico 2D (líneas, rectángulos, círculos, arcos, polilíneas y textos), cálculo topográfico automático de áreas y perímetros, metrados y descuento de vereda, capas con visibilidad/bloqueo/colores, y exportación/importación JSON, SVG y PNG.
